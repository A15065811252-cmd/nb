## 材质和灯光

- 深木色用于地板、门、扶手和床架。门把、扶手和踏板边缘有适度磨损，木纹方向与构件一致。
- 墙面用低饱和灰绿和低对比的小图案。窗帘用暗红布，床品偏米白，布料以自然褶皱为主。
- 灰蓝窗光负责照亮路线。床边暖光只照亮附近家具和人物，走廊和门把在默认亮度下仍可辨认。
- 第一批家具放在同一盏灯下对比。先看比例和轮廓，再统一木色、反光和磨损。模型来源、下载页、授权和改动记录随资产保存。
